# Concept Chatbot

A simple Python-based minor project that acts as a topic/concept chatbot. It helps users understand key concepts in computer science and technology.

## Topics Covered
- Artificial Intelligence (AI)
- Machine Learning (ML)
- Python
- Object-Oriented Programming (OOP)
- DBMS
- Networking
- Algorithms
- Cybersecurity

## Run the project
```bash
python3 chatbot.py
```

## Example interaction
```text
Welcome to Concept Chatbot!
Ask a question or type 'exit' to stop.

You: What is AI?
Bot: Artificial Intelligence (AI) is the field of computer science focused on creating systems that can perform tasks that typically require human intelligence...

You: exit
Bot: Goodbye! Keep learning.
```
