# Concept Chatbot

A simple topic/concept chatbot built in Python.

It answers common technical questions such as:
- What is AI?
- Explain Machine Learning
- What is Python?
- What is OOP?
- What is DBMS?
- What is Networking?

## How to run
```bash
python3 chatbot.py
```

## Example
```text
Welcome to Concept Chatbot!
Ask about a topic. Type 'exit' to stop.

You: What is AI?
Bot: Artificial Intelligence (AI) is the field of computer science that aims to build systems capable of reasoning, learning, and decision-making similar to humans.

You: exit
Bot: Goodbye! Keep learning.
```
